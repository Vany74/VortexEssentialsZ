# KingdomSMP 0.4.0

## Corrections et améliorations
- Toutes les nouvelles couronnes reçoivent désormais l'enchantement **Malédiction de lien (Curse of Binding)**.
- Correction du nom du motif de trim de Wealth : `Bolt` correspond au motif réellement utilisé (`TrimPattern.BOLT`).
- Le nettoyage des effets de couronne ne supprime plus systématiquement les effets de potion étrangers à KingdomSMP : seuls les types suivis comme appliqués par le plugin sont ciblés.
- Les effets passifs ne remplacent pas volontairement une potion plus forte ou plus longue déjà active.
- Version affichée dans le statut et le journal de démarrage mise à jour en 0.4.0.

## Compilation
Le code source a été modifié, mais la compilation avec Paper API 1.21.11 doit encore être exécutée dans un environnement Maven avec accès aux dépôts de dépendances. Ce ZIP n'est pas un JAR compilé.
