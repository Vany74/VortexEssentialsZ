# KingdomSMP 0.5.0 — Événements difficiles

- Les événements sont moins fréquents : vérification par défaut toutes les 90 secondes avec 12 % de chance de démarrage.
- Durée portée à 5 minutes.
- Chasse aux monstres : 40 monstres hostiles requis.
- Extraction : 48 minerais précieux requis ; charbon et cuivre ne comptent plus.
- Récompense par défaut portée à 6 matériaux de couronne.
- Les limites minimales sont appliquées dans le code, même si la configuration contient des valeurs plus faibles.
- Version du plugin et artifact Maven : 0.5.0.

Compatibilité cible : Paper 1.21.11, Java 21. Compilation et tests en jeu restent à effectuer dans l’environnement du serveur.
