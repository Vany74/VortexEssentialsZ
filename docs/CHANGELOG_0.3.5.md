# KingdomSMP 0.3.5

- Shift + clic droit pour ouvrir le menu des pouvoirs est désactivé par défaut.
- Le réglage `settings.activation.shift-clic-droit-menu` permet de réactiver cette méthode dans `config.yml`.
- Correction du cas où le menu s’ouvrait malgré tout en tenant la main vide : le réglage est désormais respecté aussi dans ce cas.
- Les autres méthodes d’activation et les fonctionnalités de la version 0.3.4 sont conservées.

Compilation Maven non vérifiée dans l’environnement de création.
