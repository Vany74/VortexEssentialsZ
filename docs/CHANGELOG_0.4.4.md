# KingdomSMP 0.4.4

- Le menu des couronnes est maintenant un écran de catégories.
- Les couronnes basiques et légendaires s’ouvrent dans deux interfaces séparées, avec un bouton de retour aux catégories.
- Les clics dans les nouveaux menus sont reconnus par le gestionnaire d’interfaces.
- La limitation configurable des dégâts de masse conserve sa configuration et ignore les auto-dégâts ainsi que les joueurs en créatif/spectateur.
- Mise à jour de la version du plugin et des instructions de build.

La compilation doit encore être effectuée avec Maven et les dépendances Paper/WorldGuard disponibles.
