# KingdomSMP 0.3.4

- GUI des pouvoirs : descriptions pour chaque capacité selon la couronne et le niveau, avec seuils de kills et état débloqué/verrouillé.
- GUI des pouvoirs : description générale de la couronne, passif et Materials Left.
- Nouveau bouton « Recettes » dans le menu principal, avec les trois objets craftables : Crown Material, Crown Upgrader et Crown Repairer.
- Recettes affichées dans le GUI : ingrédients, disposition et usage.
- Descriptions du GUI localisées en français, anglais et espagnol.

Les recettes déjà enregistrées par le plugin sont conservées. La compilation n'a pas pu être testée car Maven n'est pas installé dans l'environnement de génération.
