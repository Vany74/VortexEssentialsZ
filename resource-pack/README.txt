KingdomSMP — resource pack de développement (0.3.3)

Contenu :
- Textures pixel-art 16x16 distinctes pour les 12 couronnes.
- Modèles d'icônes et définition d'item pour les couronnes avec CustomModelData 1000 à 1011.
- Aperçu actualisé : preview-ressource-pack.png.

Installation de test :
1. Compresser le contenu du dossier resource-pack (pack.mcmeta doit être à la racine du ZIP).
2. Installer le ZIP côté client ou le fournir via l'hébergement du resource pack.
3. Vérifier les icônes en inventaire sur la version Minecraft cible.

Limite : ce pack est un prototype. La définition d'item peut changer selon la version exacte du client, et le modèle d'inventaire ne change pas automatiquement la texture de l'armure lorsqu'elle est portée sur la tête. Le rendu porté doit être créé/validé séparément avant une distribution publique.
