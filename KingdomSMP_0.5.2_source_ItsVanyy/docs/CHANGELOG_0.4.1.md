# KingdomSMP 0.4.1

- Les couronnes KingdomSMP sont retirées des drops à la mort.
- Après le respawn, la couronne enregistrée dans le profil est automatiquement remise dans l’emplacement du casque.
- Les doublons de la couronne enregistrée sont retirés de l’inventaire.
- Si un casque normal occupait l’emplacement, il est déplacé dans l’inventaire (ou déposé au sol si l’inventaire est plein).
- La restauration est ignorée si le joueur a perdu sa couronne via le mécanisme d’absorption de King.

Compilation et test serveur non exécutés dans cet environnement.
