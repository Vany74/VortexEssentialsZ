# KingdomSMP 0.3.7

- Reworked descriptions of all crown passives and active abilities in French, English and Spanish.
- Nature's knockback and area attack now affect hostile living entities, including players, while respecting the trust list.
- Wealth's first active now grants a more balanced Luck/Hero of the Village boost instead of an excessive Luck level.
- Fixed Adaptation's base passive refresh so it does not overwrite its temporary Resistance upgrades.
- Existing crown names, unlock thresholds (normal: 3/5/8; legendary: 3/5/8/12/15), materials system and Shift-right-click default remain unchanged.
