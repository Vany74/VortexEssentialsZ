# KingdomSMP 0.5.2 — Événements renforcés

Auteur : ItsVanyy
Cible : Paper 1.21.11 · Java 21 · Maven

## Objectifs des événements
- Extraction extrême : 512 minerais (au lieu de 256).
- Grande chasse : 200 monstres hostiles (au lieu de 100).
- Maître pêcheur : 128 poissons (au lieu de 64).
- Récolte royale : 384 cultures mûres (au lieu de 192).
- Déforestation : 768 bûches (au lieu de 256, objectif triplé).

Les objectifs minimums sont appliqués dans le code et restent configurables à la hausse. Intervalle de 3 heures et durée de 15 minutes conservés.

Compilation et tests en jeu à effectuer avec `mvn clean package` puis sur un serveur de test Paper 1.21.11.
